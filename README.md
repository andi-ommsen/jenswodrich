# jenswodrich.de

Persönliche Portfolio-Webseite von Jens Wodrich.

Der Titel des Browser-Tabs folgt dem aktuell sichtbaren Menüpunkt im Format
`<Menüpunkt> | Jens Wodrich`. Beim Wechsel läuft eine kurze Punktanimation;
die Systemeinstellung für reduzierte Bewegung wird berücksichtigt.

Die Kontaktadresse wird im sichtbaren Profil maskiert und erst beim Klick auf
„E-Mail senden“ clientseitig für den Aufruf des lokalen E-Mail-Programms zusammengesetzt.
